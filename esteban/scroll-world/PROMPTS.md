## PASO 5 — Codifica todo para que el scroll no se trabe

Cuando tengas los 11 videos (6 dive + 5 conn), párate en esa carpeta y corre:

```bash
for f in dive_*.mp4 conn_*.mp4; do
  ffmpeg -i "$f" -an -vf "unsharp=5:5:0.8:5:5:0.0" \
    -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p \
    -g 8 -keyint_min 8 -sc_threshold 0 -movflags +faststart "encoded_$f"
done
```
